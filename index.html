Analista Técnico

Indicadores técnicos y señales calculadas en tiempo casi real para acciones, BMV y cripto. No es asesoría financiera.

--:--:-- -- --- ----
Vista previa limitada Estás viendo este aplicativo dentro de la vista previa de Claude, que bloquea las conexiones a APIs externas por seguridad (por eso ves "Failed to fetch"). Descarga el archivo .html y ábrelo directamente en tu navegador, o súbelo a GitHub Pages — ahí las llamadas a Twelve Data y CoinGecko funcionan con normalidad.
Antes de usarlo Esta herramienta calcula indicadores técnicos estándar (medias móviles, RSI, MACD, Bandas de Bollinger) y combina esas señales en una recomendación heurística. Es información para apoyar tu propia decisión, no una recomendación de inversión garantizada. Ningún indicador predice el futuro con certeza — verifica siempre con más de una fuente y considera tu propio perfil de riesgo.

Configuración de datos

Sin API key — solo funcionará el módulo de cripto (CoinGecko no requiere key).
Obtén una key gratuita en twelvedata.com (plan Basic, 800 llamadas/día). Cobertura BMV en el plan gratuito es limitada — si un ticker mexicano falla, prueba el formato "TICKER:BMV" o revisa disponibilidad en tu cuenta de Twelve Data. Cripto usa CoinGecko sin necesidad de key.
